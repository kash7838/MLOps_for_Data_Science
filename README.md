# MLOps for Data Science

Data Scientist: They primarily focus on model development, creating accurate high-performing algorithms. 
There's a huge gap between a model that works on jupyter notebook or locally and the one that works in production. 
So, they need to understand how to package their model properly or who understand how the model will run in production later. 
They can create reproducible training pipelines and implement proper versioning which will be much more effective than someone who simply hands off a notebook to engineering team and hopes for the best in deployement.
